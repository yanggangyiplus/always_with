# copy-check

문구를 공개하기 전에 한 줄씩 아래 5가지를 확인한다.

1. 사실: 기능이 실제로 구현돼 있는가. `03_개발/README.md`와 코드로 확인한다. 구현하지 않은 기능은 "예정"이라고 쓴다.
2. 수치: 출처가 `03_개발/docs/평가리포트.md`에 있는가. 합성 시퀀스 결과면 "시험용 시나리오 기준"이라고 쓴다.
3. 과장: "모든", "100%", "절대", "의료", "진단", "생명을 구한다" 같은 표현이 없는가.
4. 저작권: 이미지, 글꼴, 템플릿의 출처와 라이선스를 적었는가. 출처를 모르면 쓰지 않는다.
5. 개인정보: 아이 영상과 사진, 실제 이름, 이메일, 위치가 없는가.

결과는 `04_마케팅/04_콘텐츠_확인.md`의 표에 "통과 / 수정 / 삭제"와 고친 문구로 남긴다. 고치기 전 문구도 함께 남긴다.
