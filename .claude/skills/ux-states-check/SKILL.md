# ux-states-check

`03_개발/frontend/src/pages/`의 화면 하나를 골라 아래 6가지를 확인한다.

1. 로딩: 데이터가 오기 전에 안내 문구(`aria-live="polite"`)가 있다.
2. 에러: 요청이 실패하면 사용자가 다음에 할 일이 문구에 있다. 권한 거부는 해결 방법을 알려 준다.
3. 빈 상태: 목록이 비면 `Empty` 컴포넌트로 다음 행동을 안내한다.
4. 긴 텍스트: 이름과 글이 아주 길어도 줄바꿈되고 화면 밖으로 나가지 않는다.
5. 작은 화면: 폭 360px에서 가로 스크롤이 생기지 않는다. Chrome DevTools로 확인한다.
6. 접근성: 부모님 화면은 본문 20px 이상, 터치 영역 48px 이상(NFR-09).

결과는 `02_디자인/03_상태화면_점검.md`의 표에 "확인함 / 미확인 / 문제"로 갱신한다. 직접 눈으로 확인하지 않은 칸은 "확인함"으로 쓰지 않는다.
