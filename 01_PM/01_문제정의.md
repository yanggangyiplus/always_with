# 문제 정의

떨어져 사는 가족은 평소 안부를 나누고 서로 도울 방법이 흩어져 있고, 위급할 때는 바로 알 방법이 마땅치 않아요.
그중 가장 급한 사례가 혼자 사는 부모님이 넘어졌을 때라서, 1차 위험 알림을 낙상 감지로 정했어요.
이후에는 외출 기록 같은 상황으로 넓혀 가요.

## 누가

사용자는 세 부류예요. 20~50대 보호자, 아이, 부모님이 한 가족으로 연결돼요.

| 구분 | 20~50대 보호자 | 아이 | 부모님 |
| --- | --- | --- | --- |
| 예시 | 타지에 사는 20~50대 자녀, 아이를 키우는 부모 | 보호자가 돌보는 아이 | 혼자 사는 60대 이상 |
| 불안 | 쓰러지거나 위험한 곳에 가도 모를까 봐 걱정 | 놀이 중 넘어지거나 위험한 곳(주방 근처)에 가고, 잠자리에서 일어나 돌아다닐 수 있음 | 자식에게 부담이 되기 싫고 감시받는 느낌이 싫음 |
| 필요 | 안부 나누기, 이상 상황의 빠른 인지와 확인 | 보호자가 곁에 없어도 위험할 때 알려 주는 것 | 최소한의 조작, 사생활 보호, 동의 존중 |
| 앱에서의 역할 | 알림 수신, 카메라 등록, 초대 코드 발급, 이벤트 확인 | 계정으로 피드와 채팅에 참여(보호자 동의 뒤 초대 코드로 연결) | 초대 코드 입력과 동의, 피드와 채팅, 부탁 |
| 동의 | 아이의 법정대리인으로서 동의를 확인 | 보호자가 동의해야 연결됨 | 본인이 초대 코드를 입력하고 직접 동의 |

- 아이와 부모님 모두 화면에서는 "부모님·아이"로 묶이지만 위험이 달라서 돌봄 대상 유형(부모님, 아이)은 나누어 다뤄요.
- 아이 대상 감지는 성인용 모델을 그대로 써서 정확도를 검증하지 못했고, 베타로 표시해요.
- 아이의 불안과 필요는 기획 단계에서 정리한 가정이고, 아이와 보호자를 대상으로 확인하지 못했어요. 발표 전에 보호자 3~5명에게 확인해야 해요.
- 아이 영상과 사진은 문서, 시연, README에 쓰지 않아요.

## 어떤 상황에서

- 부모님이 집에서 넘어졌는데 일어나지 못하는 상황이에요.
- 아이가 보호자 눈이 닿지 않는 곳(주방 근처)에 가거나 잠자리에서 일어나 돌아다니는 상황이에요.
- 보호자는 일하는 중이거나 멀리 있어서 전화를 바로 못 해요.
- 평소에는 서로 안부를 묻고 필요한 일을 부탁하고 싶은데 연락 수단이 흩어져 있어요.

## 왜 불편한가

| 기존 방법 | 모자란 점 |
| --- | --- |
| 웨어러블 | 착용을 잊거나 거부해요 |
| 일반 홈캠 | 보호자가 계속 영상을 봐야 하고, 부모님은 감시받는 느낌이 들어요 |
| 정기 전화 | 전화 사이에 생긴 사고를 모르고, 부모님이 "괜찮다"고만 답해요 |
| 아이용 홈캠 | 보호자가 계속 영상을 봐야 하고, 위험한 구역이나 취침 이탈은 직접 알려 주지 않아요 |

## 근거

근거로 쓴 것은 기획 단계에서 정리한 배경([기획문서.md](./기획문서.md) 1.1)이에요.
통계 수치는 확인한 출처가 없어서 쓰지 않았어요. 발표 전에 낙상 관련 공개 통계(통계청, 질병관리청)를 찾아 출처와 함께 이 문서에 추가해야 해요.

## 해결 방향

1. 피드, 채팅, 부탁, 일정, 위치 공유로 가족이 서로를 돌봐요(쌍방향).
2. 위험 알림은 평소에는 조용히 있고 이상할 때만 알려요(1차는 낙상).
3. 평소에는 관절 선 화면만 보여 주고 영상은 저장하지 않아요. 이상 감지 시 짧은 클립 저장은 준비 중이에요.
4. 부모님이 직접 동의해야 연결돼요.
5. 오탐을 신고하면 개선 후보로 쌓여요.
