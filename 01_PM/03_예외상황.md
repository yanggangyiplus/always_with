# 예외 상황 정의

사용자가 중간에 그만두거나 데이터가 없을 때 서비스가 어떻게 행동하는지 정했어요.
"구현" 칸은 코드와 테스트로 확인한 것만 "예"라고 적었어요.

| 상황 | 정의한 동작 | 구현 | 근거 |
| --- | --- | --- | --- |
| 부모님이 동의하지 않고 이탈 | 연결되지 않고, 카메라를 등록할 수 없어요 | 예 | `cameras.py`, `test_invite_flow` |
| 초대 코드 만료 또는 재사용 | "만료되었거나 사용된 코드입니다" 안내 | 예 | `invites.py`, `test_invite_expiry_and_lock` |
| 초대 코드를 계속 틀림 | 10분간 잠금(429) | 예 | 같은 테스트 |
| 아이 프로필에 보호자 동의가 없음 | 카메라 등록과 계정 연결이 막혀요 | 예 | `test_child_consent_and_permissions` |
| 연결되지 않은 사람이 영상과 이벤트를 조회 | 403 | 예 | `deps.py` |
| 카메라 권한을 거부 | 허용 방법을 안내 | 예 | `Stream.tsx` |
| 카메라가 오프라인 | 구역 설정이 막혀요 | 예 | `zones.py` |
| 이벤트가 없음 | "아직 이벤트가 없어요" 빈 화면 | 예 | `Home.tsx`, `Timeline.tsx` |
| 카메라가 없음 | "등록된 카메라가 없어요" 안내 | 예 | `Cameras.tsx` |
| 잘못된 알림 | 오탐 신고, 되돌릴 수 없다고 확인 후 변경 | 예 | `EventDetail.tsx` |
| 사람이 여러 명 | 가장 크게 보이는 사람 기준 | 예 | `pose.py` |
| 관절이 잘 안 보임(신뢰도 낮음) | 판정하지 않아요(놓칠 수 있음) | 예 | `fall_rule.py`, 평가 N09 |
| 피드 공개 범위 밖의 글을 채팅에서 인용 | 내용을 가려요 | 예 | `family.py`, `test_chat_reply_to_post` |
| 위치 공유를 끔 | 저장된 위치를 지워요 | 예 | `test_chat_location_and_child_account` |
| 위치 권한을 거부 | 안내 문구 | 예 | `location.tsx`, `Feed.tsx` |
| 서버가 꺼짐 | 사용자에게 오류 문구 | 일부 | 요청 실패 문구만 확인했고 재시도는 없어요 |
| 서버를 여러 대 띄움 | 카메라별 판정 상태가 갈라져요 | 아니오 | `pose.py`에 한계를 주석으로 남겼어요 |
