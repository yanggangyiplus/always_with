# 사용자 테스트

아직 실시하지 않았어요. 아래는 3~5명에게 같은 방식으로 실시하기 위한 계획이고, 결과 표는 비어 있어요.
결과를 채우기 전에는 발표 자료에 사용자 테스트 결과를 쓰지 않아요.

## 목표

- 보호자가 도움 없이 "가입, 아이나 부모님 등록, 카메라 켜기, 알림 확인"까지 끝낼 수 있는지 봐요.
- 지표는 과업 성공률과 소요 시간이에요.

## 참가자

- 3~5명. 리뷰 그룹 동료 또는 가족.
- 개인정보는 수집하지 않고 "참가자 1, 2, 3"으로만 기록해요.
- 아이 영상은 사용하지 않아요.

## 과업

| 과업 | 성공 기준 | 제한 시간 |
| --- | --- | --- |
| T1. 이메일로 가입한다 | 홈 화면 도착 | 2분 |
| T2. 부모님을 추가하고 초대 코드를 만든다 | 6자리 코드를 읽어 줌 | 3분 |
| T3. 카메라를 등록하고 웹캠을 켠다 | 관절 선이 화면에 보임 | 3분 |
| T4. 이벤트 상세를 열어 "확인 완료"로 바꾼다 | 상태가 바뀜 | 2분 |
| T5. 이상한 입력을 넣어 본다 (빈 칸, 긴 글, 잘못된 코드) | 막히는 이유를 이해함 | 3분 |

## 결과 기록표

| 참가자 | T1 | T2 | T3 | T4 | T5 | 막힌 곳 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 미실시 | | | | | |
| 2 | 미실시 | | | | | |
| 3 | 미실시 | | | | | |

칸에는 "성공(초)" 또는 "실패(이유)"를 적어요. 리뷰 그룹 상호 테스트 결과도 같은 표에 넣어요.
