## 꼭 할 말

- 소통 지표는 두 계정에서 피드와 채팅이 몇 초 안에 서로 보이는지예요. 두 창을 나란히 놓고 시연으로 보여 줘요.
- 소통 지표 값은 직접 잰 값만 말해요. 재지 못했다면 "측정 방법까지 정했다"고 말해요.
- 채팅과 피드는 3초마다 새로 불러오는 방식이고 진짜 실시간(WebSocket)은 아니에요.
- 낙상은 오탐률을 57%에서 21%로 줄였지만 경보가 1.1초 늦어졌고, 이것이 맞바꾼 것이에요.
- 낙상 수치는 합성 시퀀스 결과이고 실제 영상 검증은 아직이에요.
- 위험 알림은 낙상으로 시작했고 외출 기록으로 넓힐 계획이에요.

## 시연 순서 (1분 30초)

1. 로그인 후 홈 화면
2. 두 창(보호자와 부모님)에서 한쪽이 피드에 글을 올리고 채팅을 보내면 다른 쪽에 나타나는 모습
3. 카메라 등록과 웹캠에서 관절 선 표시
4. 낙상 이벤트가 타임라인에 쌓이고 상세에서 확인 완료
5. 막는 장면: 잘못된 초대 코드 입력 또는 카메라 권한 거부 안내

시간이 모자라면 2번과 3번을 각각 한 장면으로 줄여요.
