# 디자인 결정

각 결정은 사용자의 불안이나 조작 부담을 줄이는 쪽으로 골랐어요.

## 원칙

1. 평소에는 조용해야 해요. 이상이 없으면 "오늘은 이상 없어요"만 보여요.
2. 이상할 때는 한눈에 보여야 해요. 확인하지 않은 알림 건수가 홈 제목이 돼요.
3. 감시처럼 보이면 안 돼요. 원본 영상 대신 관절 선을 보여 줘요.
4. 부모님 화면은 크고 단순해야 해요. 본문 20px 이상, 터치 영역 48px 이상이 목표예요(NFR-09).

## 결정과 근거

| 화면 | 결정 | 근거 |
| --- | --- | --- |
| 전체 | 보라색 계열, 디자인 스튜디오 템플릿(MIT)을 참고 | 차갑지 않은 첫인상으로 의료 기기처럼 보이지 않게 하려고요 |
| 전체 | 탭을 위쪽에 고정하고, 서비스 이름을 누르면 홈으로 | 화면이 어디든 한 번에 홈으로 돌아와요. 첫 화면에서 서비스 1개 이상이 보여야 한다는 요구가 있었어요 |
| 보호자 홈 | 제목이 상태 문장("확인하지 않은 알림이 N건 있어요" 또는 "오늘은 이상 없어요") | 숫자 대시보드보다 읽는 시간이 짧아요 |
| 부모님·아이 홈 | 확인할 것, 연결된 가족, 서비스 소개를 따로 보여 줌 | 부모님은 보호자 기능이 필요 없고, 할 일이 먼저 보여야 해요 |
| 카메라 | 관절 선 화면과 "카메라가 켜져 있어요" 상태 표시 | 켜져 있는지 부모님이 알아야 동의가 의미 있어요 |
| 이벤트 상세 | 확인 완료나 오탐 신고 전에 "한 번 바꾸면 되돌릴 수 없어요" 확인 | 알림 오조작으로 기록이 틀어지는 것을 막아요 |
| 위치 | 본인이 켰을 때만 공유, 꺼져 있으면 "공유를 켜지 않았어요" | 감시가 아니라 안부를 나누는 느낌이 목표예요 |
| 피드 | 사진 5장, 사진 아래에 글, 좋아요만(댓글 없음) | 소통은 하되 부담스러운 반응 압박은 줄여요 |
| 가족 소개 | 랜딩에 의료기기 아님, 동의 필요 문구를 항상 노출 | 책임 범위를 첫 화면에서 알려요 |

## 개선 전후 화면

| 화면 | 전 | 후 | 이유 |
| --- | --- | --- | --- |
| 카메라 | 별도 스크립트 창에서만 관절이 보임 | 사이트 카메라 화면에서 관절이 보임 | 보호자가 앱 밖으로 나가지 않아도 돼요 |
| 카메라 | 거울 반전에 글자도 뒤집힘 | 화면은 반전, 글자는 정상 방향 | 읽을 수 있어야 해요 |
| 피드 | 사진과 글, 위치만 | 내 피드와 가족 피드, 공개 범위 선택 | 누구에게 보일지 정하게 해요 |

화면 캡처(전후 이미지)는 이 폴더에 넣지 않았어요. 발표 자료에 실제 화면을 붙일 때 추가해요.
