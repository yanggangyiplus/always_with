# 로딩, 에러, 빈 화면 점검

코드에서 안내 문구를 찾아 정리했어요. "코드 확인"은 소스에 문구가 있다는 뜻이고, 브라우저에서 눈으로 본 것은 아니에요.
눈으로 확인하면 `ux-states-check` 스킬로 "화면 확인" 칸을 채워요.

| 화면 | 로딩 | 에러 | 빈 상태 | 화면 확인 |
| --- | --- | --- | --- | --- |
| 홈(보호자) | "불러오는 중…" | - | "아직 이벤트가 없어요", "아직 등록된 카메라가 없어요" | 미확인 |
| 홈(부모님·아이) | "불러오는 중" | - | "연결된 가족이 아직 없어요", "다가오는 일정이 없어요" | 미확인 |
| 카메라 목록 | - | - | "등록된 카메라가 없어요. 아래에서 첫 카메라를 등록해 보세요." | 미확인 |
| 카메라 스트림 | 권한 대기 문구 | 카메라 권한 허용 방법 안내 | - | 미확인 |
| 타임라인 | - | - | "조건에 맞는 이벤트가 없어요" | 미확인 |
| 이벤트 상세 | "불러오는 중…" | 클립이 없을 때 안내 | - | 미확인 |
| 피드 | 사진 불러오는 칸 | 위치 권한 안내 | 내 피드와 가족 피드 각각 안내 | 미확인 |
| 일정 | - | - | "이 날은 일정이 없어요" | 미확인 (모바일 레이아웃 변경 후 확인 안 함) |
| 부탁해 | - | - | "아직 부탁한 일이 없어요" | 미확인 (모바일) |
| 위치 | "불러오는 중…" | 위치 권한 안내 | "위치를 볼 가족이 아직 없어요", "아직 위치가 도착하지 않았어요" | 미확인 (모바일) |
| 소셜 로그인 완료 | - | "로그인에 실패했어요" | - | 미확인 |
| 모든 화면 | - | 요청 실패는 서버가 준 문구 또는 "요청에 실패했어요" | - | 미확인 |

## 아직 코드에 없는 것

- 로딩 문구가 없는 화면(카메라 목록, 타임라인, 일정, 부탁해)은 빈 화면과 로딩을 구분하지 못해요.
- 에러 전용 화면(서버 꺼짐)은 없어요.
- 긴 텍스트, 폭 360px 이하에서 깨지는지는 확인하지 못했어요.
- 부모님 화면 글자 20px, 터치 48px 기준은 측정하지 않았어요.

## 다음에 할 일

1. Chrome DevTools로 폭 360px, 768px에서 화면 12개를 캡처해요.
2. 긴 이름(40자)과 긴 글(500자)을 넣어 줄바꿈을 확인해요.
3. 로딩 문구가 없는 화면에 추가해요.
