# 타깃과 핵심 메시지

1차 타깃은 20~50대 보호자예요. 부모님과 아이는 앱을 함께 쓰는 가족이고, 부모님은 "설득할 사람"이에요.

## 타깃

| 구분 | 20~50대 보호자(설치 결정) | 부모님(수락 결정) | 아이(보호자 동의 후 사용) |
| --- | --- | --- | --- |
| 누구 | 타지에 사는 20~50대 자녀, 아이를 키우는 부모 | 혼자 사는 60대 이상 | 보호자가 돌보는 아이 |
| 상황 | 일하는 중에 "혹시 쓰러지셨으면", "아이가 위험한 곳에 갔으면" 하는 걱정이 들어요 | 자식에게 부담이 되기 싫어요 | 보호자가 곁에 없을 때 위험한 곳에 갈 수 있어요 |
| 걸림돌 | 영상을 계속 볼 시간이 없어요 | 감시받는 느낌, 조작이 어려움 | 정확도 미검증(베타), 법정대리인 동의 필요 |
| 알릴 포인트 | 이상할 때만 알려요 | 평소에는 관절 선만 보여요. 동의해야 연결돼요 | 보호자가 동의한 뒤에만 연결돼요. 베타예요 |

아이에게는 직접 홍보하지 않고 보호자에게만 알려요. 아이 영상과 사진은 홍보에 쓰지 않아요.

## 핵심 메시지

한 문장: "언제 어디서나 서로를 돌보고, 이상할 때만 알려요."

보조 문장: "평소에는 피드와 채팅으로 안부를 나누고, 위험할 때만 알림이 울려요."

| 근거 메시지 | 보여 줄 증거 |
| --- | --- |
| 영상을 계속 보지 않아도 돼요 | 홈 화면 "오늘은 이상 없어요" |
| 부모님의 사생활을 지켜요 | 평소에는 관절 선만 보이고 영상은 저장되지 않아요(클립 저장은 준비 중) |
| 부모님이 직접 동의해야 연결돼요 | 초대 코드 6자리, 10분 만료, 동의 전 카메라 등록 불가 |
| 가족이 서로 돌봐요 | 가족 피드, 실시간 채팅, 부탁해, 일정, 위치 공유 |
| 부모님과 아이를 한 앱에서 돌봐요 | 돌봄 대상 유형 구분 |
| 위험 알림은 점점 넓어져요 | 지금은 낙상, 이후 외출 기록(예정이라고 표시) |

## 하지 않을 말

- "모든 낙상을 감지해요", "100% 정확해요", "생명을 지켜요"
- "의료", "진단", "치료" 표현
- 구현하지 않은 기능(푸시 알림, 학습 모델 기반 정확도)을 이미 되는 것처럼 쓰는 말
- 아이 영상이나 사진을 쓰는 홍보
- 실제 정확도처럼 읽히는 수치. 수치를 쓸 때는 "시험용 시나리오 기준"이라고 써요.

## 신뢰를 주는 말 (그대로 써도 되는 문구)

랜딩 페이지에 이미 있는 문구예요.

- "이 서비스는 의료기기가 아닌 보조 알림 도구이며 모든 낙상을 감지한다고 보장하지 않습니다. 촬영 대상자의 동의가 필요하고, 평소 영상은 저장하지 않습니다."
