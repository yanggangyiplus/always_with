# 콘텐츠 확인

생성한 문구를 공개하기 전에 사실, 과장, 저작권, 개인정보 네 가지를 확인해요. 절차는 `copy-check` 스킬이에요.

## 확인 기준

| 항목 | 기준 |
| --- | --- |
| 사실 | 구현된 기능만 "된다"고 써요. 없는 기능은 "예정"이에요 |
| 수치 | 평가 리포트에 있는 값만 쓰고, 합성 시나리오 기준이라고 써요 |
| 과장 | "모든", "100%", "절대", "의료", "진단" 금지 |
| 저작권 | 이미지, 글꼴, 템플릿의 출처와 라이선스를 적어요 |
| 개인정보 | 아이 영상과 사진, 실제 이름, 이메일, 위치 금지 |

## 남은 확인

- 부모님 연결 동의 화면(`Connect.tsx`)과 아이 동의 체크(`AddRecipient.tsx`)의 "클립 보관" 문구도 "영상은 저장하지 않아요"로 고쳤어요. 클립 저장을 구현하면 동의 문구를 다시 정해야 해요.

- 랜딩 이미지(`hero.png`)의 출처와 라이선스를 확인하지 못했어요. 확인 전에는 공개 홍보에 쓰지 않아요.
- 홍보 영상에 가족이 나오면 출연자 동의를 받고, 아이는 출연시키지 않아요.
