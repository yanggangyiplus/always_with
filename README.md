# Always with

Always with는 언제 어디서나 가족이 서로를 돌볼 수 있는 가족 돌봄 웹앱이에요. 나중에는 모바일 앱으로 옮길 예정이에요.
가족끼리 피드를 공유하고, 실시간으로 채팅하고, 대신 해 달라고 부탁하고, 위험이 생기면 알림을 받아요.
위험 알림은 지금은 낙상 감지로 시작했고, 이후 외출 기록 같은 상황으로 넓혀 가요.
영상은 평소에 관절 선으로만 보여 주고 저장하지 않아요. 이상 감지 클립 저장은 준비 중이에요.

이 서비스는 의료기기가 아닌 보조 알림 도구예요. 모든 낙상을 감지한다고 보장하지 않아요.

## 문제와 해결

- 떨어져 사는 가족은 서로의 안부와 필요한 일을 챙길 창구가 흩어져 있어요.
- 타지에 사는 20~50대 보호자는 혼자 사는 부모님이 쓰러지거나 아이가 위험한 곳에 가도 바로 알 방법이 없어요.
- 웨어러블은 착용을 잊기 쉽고, 일반 홈캠은 계속 봐야 하며 부모님이 감시받는 느낌을 받아요.
- Always with는 피드, 채팅, 부탁, 일정, 위치 공유로 평소의 소통을 한 곳에 모아요.
- 위험 알림은 포즈 추정(YOLO 관절 검출)과 규칙으로 낙상을 판정하고, 이상할 때만 보내요.
- 문제 정의와 근거는 [01_PM/01_문제정의.md](./01_PM/01_문제정의.md)에 있어요.

## 빠른 실행

필요한 것은 Python 3.11 이상, Node.js 20 이상이에요.

```bash
# 백엔드 (포트 8000)
cd 03_개발/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

# 프론트엔드 (포트 5173, 다른 터미널)
cd 03_개발/frontend
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열어요. 프론트가 `/api` 요청을 8000번 포트로 넘겨요.

- 관절 검출 모델은 저장소에 없어요. 처음 `ultralytics`가 모델 이름을 받을 때 내려받거나, `yolo26n-pose.pt`를 `03_개발/ml/`에 직접 넣어요.
- 카메라 화면은 첫 분석 요청 때 모델을 불러오므로 첫 프레임이 느려요.
- 소셜 로그인(구글, 카카오, 네이버)은 키가 없으면 "준비 중"으로 표시돼요. 이메일 로그인은 키 없이 돼요.
- 환경변수는 [03_개발/README.md](./03_개발/README.md)에 정리했어요.

테스트와 평가는 아래처럼 돌려요.

```bash
cd 03_개발/backend && python -m pytest -q      # 20개
cd 03_개발 && python ml/eval/eval_fall_rule.py  # 낙상 규칙 전후 비교, 결과는 ml/eval/results.md
```

## 확인한 수치

### 소통 지표

연결된 두 계정에서 피드와 채팅이 서로 화면에 몇 초 안에 나타나는지를 지표로 정했어요(목표 5초 이내).
아직 재지 못했어요. 정의와 목표는 [01_PM/02_성공지표_우선순위.md](./01_PM/02_성공지표_우선순위.md)에 있어요.

### 낙상 규칙

합성 관절 시퀀스 26건(낙상 12, 일상 14)으로 단순 기준선 v0와 현재 규칙 v1을 비교했어요.

| 지표 | v0 단순 기준선 | v1 현재 규칙 |
| --- | --- | --- |
| 재현율 | 92% | 92% |
| 오탐률 | 57% | 21% |
| 경보 지연 | 0.0초 | 1.1초 |

- 오탐률을 57%에서 21%로 줄이는 대신 경보가 1초가량 늦어져요.
- 이 수치는 직접 만든 궤적이라 실제 정확도가 아니에요. 실제 영상 검증은 아직 하지 않았어요.
- 건별 결과와 실패 원인은 [03_개발/docs/평가리포트.md](./03_개발/docs/평가리포트.md)에 있어요.

## 안정성

- 이상 입력, 권한 없는 접근, 동의 없는 카메라 연결, 초대 코드 오입력을 서버에서 막고 테스트로 확인해요.
- 카메라 권한 거부, 빈 목록, 로딩 상태는 화면에서 안내 문구를 보여 줘요.
- 막는 항목과 근거 파일은 [03_개발/docs/안정성.md](./03_개발/docs/안정성.md)에 있어요.

## 한계

- 낙상 기준값(몸통 60도, 1초 유지, 직전 5초 안에 서 있었음)은 가정값이에요.
- 천천히 눕는 동작, 숙이는 동작, 카메라 쪽으로 쓰러지는 동작은 구분하지 못해요.
- 아이 대상 감지는 성인용 모델을 그대로 써서 정확도를 보장하지 않아요.
- 이상 감지 클립 저장, Web Push 발송, 영상 파일 업로드 분석, 위험 구역 판정은 아직 없어요. 구현 상태는 [기획문서](./01_PM/기획문서.md)의 "구현 상태" 열에 있어요.
- 채팅과 피드는 3초마다 새로 불러와요.
- 배포 주소와 시연 영상은 제출 때 따로 올려요.
